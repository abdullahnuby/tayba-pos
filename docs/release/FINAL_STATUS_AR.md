# الحالة الحالية — تحويل طيبة POS إلى تشغيل محلي

هذا التقرير يصف فرع `local-only-hardening` ولا يعني أن النسخة جاهزة لتشغيل بيانات المحل.

## البنية المستهدفة
- Next.js على Node.js مع Prisma Client القياسي.
- SQLite محلية واحدة في `data/tayba.db`.
- نسخة كاملة قابلة للتنزيل من شاشة «النسخ الاحتياطي».
- لا يعتمد التشغيل اليومي على Google Sheets أو Apps Script أو Cloudflare D1/KV.

## تغييرات الفرع
تمت إضافة طبقة معاملات SQLite للبيع والشراء والمرتجعات والجرد والإلغاء والاستئناف. تمت مراجعة ترابط المدفوعات مع الأرصدة، وتقرير الربح بعد المرتجعات، وإغلاق الوردية. أزيلت تكاملات Cloudflare/Google القديمة من شجرة التشغيل، وأضيف مسار تحقق عبر GitHub Actions يشمل Prisma وTypeScript وESLint والبناء.

## ما يمنع اعتماد الإصدار حاليًا
- نجاح GitHub Actions على أحدث commit.
- اختبار التطبيق عمليًا بقاعدة SQLite تجريبية، بما يشمل العمليات المالية والمخزون.
- فحص نسخة قاعدة البيانات الاحتياطية وتجربة استعادتها في ملف منفصل.
- استيراد بيانات المحل ومطابقة أعداد السجلات والمخزون والأرصدة قبل فتح النسخة للعمل.

**لا تدمج الفرع ولا تشغله على قاعدة المحل الحالية حتى تُستوفى بوابة التحقق أعلاه.** رفع التعديلات إلى GitHub لا يثبت وحده أن جميع العمليات نُفذت واختُبرت في بيئة تشغيل.
